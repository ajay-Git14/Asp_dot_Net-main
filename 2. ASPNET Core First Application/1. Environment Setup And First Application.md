# 5. .NET SDK Setup Check

## What

The **.NET SDK** is required to build and run ASP.NET Core applications.

SDK means:

```text
Software Development Kit
```

It includes:

```text
Compiler
Runtime
Command-line tools
Project templates
Build tools
```

## Why

Without the .NET SDK, we cannot create or run ASP.NET Core applications.

## How To Check

Open Command Prompt or Terminal and run:

```bash
dotnet --version
```

To see all installed SDKs:

```bash
dotnet --list-sdks
```

To see installed runtimes:

```bash
dotnet --list-runtimes
```

## Expected Understanding

Learner should understand:

```text
SDK is used by developers to build applications.
Runtime is used to run applications.
For development, SDK is required.
```

## Common Mistake

| Mistake                             | Correction                                             |
| ----------------------------------- | ------------------------------------------------------ |
| Installing only runtime             | Install SDK for development                            |
| Multiple SDK confusion              | Use the SDK selected by Visual Studio project template |
| Not checking installed version      | Run `dotnet --list-sdks`                               |
| Thinking SDK and framework are same | SDK includes tools; runtime executes apps              |

## Smart Society Mapping

The .NET SDK will compile and run the Smart Society ASP.NET Core MVC application.

## Common Local Server Names


```text

```

## Common Mistake

| Mistake                                      | Correction                                           |
| -------------------------------------------- | ---------------------------------------------------- |
| SQL Server installed but service not running | Start SQL Server service                             |
| SSMS installed but SQL Server missing        | Install SQL Server engine also                       |
| Wrong server name                            | Try `(localdb)\MSSQLLocalDB`, `.`, or `.\SQLEXPRESS` |
| Confusing database with table                | Database contains tables                             |
| Hardcoding connection string blindly         | Understand server name and database name             |

# 12. Understand Localhost And Development Server

## What Is Localhost?

`localhost` means:

```text
This computer itself
```

When we run the application locally, the browser sends request to the same machine.

Example:

```text
https://localhost:7042
```

This means:

```text
Run the web application from my own development machine on port 7042
```

## What Is Port?

A port is like a door number for an application running on your machine.

Example:

```text
localhost:7042
```

Here:

```text
localhost = your machine
7042 = application port
```

## What Is Development Server?

ASP.NET Core uses a development server to run the application locally.

In ASP.NET Core, the built-in web server is commonly known as:

```text
Kestrel
```

During development, Visual Studio starts the application and opens it in the browser.

## Real-Life Analogy

Think of a building:

```text
localhost = building address
port = flat number
application = person living in that flat
```

If the browser wants to talk to the application, it must know both:

```text
Address + Port
```
