# Core Building Blocks

## 1. Program Structure

A C# program has an entry point where execution begins.

### Simple Example

```csharp
Console.WriteLine("Smart Society Issue Management System");
```

### Modern C# Minimal Program

```csharp
Console.WriteLine("Application started");

```

### Project Mapping

```text
Program starts
    ↓
Complaint value is created
    ↓
Value is displayed
```

## 2. Variables

A variable stores a value.

### Example

```csharp
string complaintTitle = "Water leakage in basement";
int complaintId = 101;
bool isResolved = false;
```

### Project Mapping

| Variable         | Meaning                                     |
| ---------------- | ------------------------------------------- |
| `complaintTitle` | Stores complaint title                      |
| `complaintId`    | Stores complaint number                     |
| `isResolved`     | Stores whether complaint is resolved or not |

---

## 3. Data Types

Data type defines what kind of value can be stored.

### Common C# Data Types

| Data Type  | Use                 | Project Example              |
| ---------- | ------------------- | ---------------------------- |
| `int`      | Whole number        | Complaint ID, total count    |
| `string`   | Text                | Title, description, category |
| `bool`     | True/false          | Is resolved, is assigned     |
| `DateTime` | Date and time       | Created date, resolved date  |
| `decimal`  | Financial value     | Maintenance amount           |
| `double`   | Decimal calculation | Rating, percentage           |
| `char`     | Single character    | Block code                   |

### Example

```csharp
int complaintId = 1;
string title = "Garbage not collected";
bool isResolved = false;
DateTime createdDate = DateTime.Now;
decimal maintenanceAmount = 2500.50m;
```

---

## 4. Operators

Operators are used to calculate, compare, and combine values.

## Arithmetic Operators

```csharp
int totalComplaints = 10;
int resolvedComplaints = 4;

int pendingComplaints = totalComplaints - resolvedComplaints;
```

## Comparison Operators

```csharp
bool isCritical = priorityScore >= 8;
```

## Logical Operators

```csharp
bool shouldEscalate = isCritical && !isResolved;
```

## Project Mapping

```text
Total complaints - resolved complaints = pending complaints

Priority score >= 8 = critical complaint

Critical complaint AND not resolved = escalation required
```

---

## 5. Type Conversion

Type conversion means converting one data type into another.

### Example

```csharp
string input = "101";
int complaintId = Convert.ToInt32(input);
```

### Safer Example

```csharp
string input = "101";

bool isValid = int.TryParse(input, out int complaintId);

if (isValid)
{
    Console.WriteLine($"Complaint ID is {complaintId}");
}
else
{
    Console.WriteLine("Invalid complaint ID");
}
```

### Project Mapping

User input usually comes as text.

```text
Form Input
    ↓
String Value
    ↓
Convert To Required Type
    ↓
Use In Application Logic
```

# Conditional Statements

## What

Conditional statements allow the program to make decisions.

## Why

Business applications are full of decisions.

Example:

```text
If complaint is critical, escalate it.
If complaint is resolved, allow closure.
If complaint is new, assign staff.
```

---

## `if` Statement

```csharp
bool isResolved = false;

if (!isResolved)
{
    Console.WriteLine("Complaint is still pending");
}
```

---

## `if else`

```csharp
bool isResolved = true;

if (isResolved)
{
    Console.WriteLine("Complaint can be closed");
}
else
{
    Console.WriteLine("Complaint cannot be closed yet");
}
```

---

## `else if`

```csharp
int priorityScore = 9;

if (priorityScore >= 8)
{
    Console.WriteLine("Critical priority complaint");
}
else if (priorityScore >= 5)
{
    Console.WriteLine("Medium priority complaint");
}
else
{
    Console.WriteLine("Low priority complaint");
}
```

---

## `switch`

```csharp
string status = "New";

switch (status)
{
    case "New":
        Console.WriteLine("Complaint needs assignment");
        break;

    case "Assigned":
        Console.WriteLine("Complaint assigned to staff");
        break;

    case "Resolved":
        Console.WriteLine("Complaint can be closed");
        break;

    default:
        Console.WriteLine("Unknown complaint status");
        break;
}
```

# Loops

## What

Loops repeat logic multiple times.

## Why

In a real project, we usually process many records.

Example:

```text
Show all complaints
Check each complaint status
Count pending complaints
Display all critical complaints
```

---

## `for` Loop

```csharp
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine($"Complaint number: {i}");
}
```

---

## `foreach` Loop

```csharp
string[] complaints =
{
    "Water leakage",
    "Lift not working",
    "Garbage not collected"
};

foreach (string complaint in complaints)
{
    Console.WriteLine(complaint);
}
```

---

## `while` Loop

```csharp
int pendingComplaints = 3;

while (pendingComplaints > 0)
{
    Console.WriteLine("Processing one pending complaint");
    pendingComplaints--;
}
```

# Practical Code Example

## Complaint Decision Logic

```csharp
string complaintTitle = "Lift not working";
string status = "New";
int priorityScore = 9;
bool isResolved = false;

bool isCritical = priorityScore >= 8;
bool shouldEscalate = isCritical && !isResolved;

Console.WriteLine($"Complaint: {complaintTitle}");
Console.WriteLine($"Status: {status}");

if (shouldEscalate)
{
    Console.WriteLine("Action: Escalate complaint immediately");
}
else if (status == "New")
{
    Console.WriteLine("Action: Assign complaint to staff");
}
else if (isResolved)
{
    Console.WriteLine("Action: Complaint can be closed");
}
else
{
    Console.WriteLine("Action: Monitor complaint");
}
```

# Common Mistakes

## 1. Using Wrong Data Type

Bad:

```csharp
string complaintCount = "10";
```

Better:

```csharp
int complaintCount = 10;
```

---

## 2. Confusing `=` And `==`

Bad:

```csharp
if (status = "New")
{
}
```

Better:

```csharp
if (status == "New")
{
}
```

---

## 3. Ignoring Case Sensitivity

```csharp
string status = "new";

if (status == "New")
{
    Console.WriteLine("Matched");
}
```

This will not match because `"new"` and `"New"` are different.

---

## 4. Not Using Braces Clearly

Bad:

```csharp
if (isResolved)
    Console.WriteLine("Resolved");
    Console.WriteLine("Closed");
```

Better:

```csharp
if (isResolved)
{
    Console.WriteLine("Resolved");
    Console.WriteLine("Closed");
}
```

---

## 5. Infinite Loop

Bad:

```csharp
int count = 1;

while (count <= 5)
{
    Console.WriteLine(count);
}
```

Better:

```csharp
int count = 1;

while (count <= 5)
{
    Console.WriteLine(count);
    count++;
}
```

# Deep Concepts

## 1. Variable Means Memory Location

A variable is not just a name. It stores a value in memory.

```text
complaintTitle → "Lift not working"
```

---

## 2. Data Type Gives Meaning

The value `101` can mean many things.

```text
Complaint ID
Flat number
User ID
Amount
```

Data type and variable name give meaning to the value.

---

## 3. Operator Creates Decision Power

Operators help the program compare and calculate.

```text
priorityScore >= 8
```

This becomes a business decision.

---

## 4. Condition Converts Rule Into Code

Business rule:

```text
Critical unresolved complaints must be escalated.
```

Code:

```csharp
if (isCritical && !isResolved)
{
    Console.WriteLine("Escalate complaint");
}
```

---

## 5. Loop Converts Repeated Work Into Automation

Instead of checking complaints one by one manually, loop automates the repeated task.
