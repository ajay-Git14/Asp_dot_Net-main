## 1. What Is HTML?

**HTML** stands for **HyperText Markup Language**.

HTML is used to create the structure of a web page.

It tells the browser what content should appear on the page.

Examples:

- Heading
- Paragraph
- Image
- Link
- Button
- Form
- Table
- List
- Section
- Navigation menu

HTML is not a programming language. It is a **markup language**.

That means HTML marks content using tags.

Example:

```html
<h1>Expert Search</h1>
<p>Find verified experts for your project requirements.</p>
```

Here:

```text
<h1>  -> Heading tag
<p>   -> Paragraph tag
```

---

## 2. Why Do We Need HTML in ASP.NET Core MVC?

ASP.NET Core MVC uses `.cshtml` files to create views.

A `.cshtml` file contains two things:

```text
HTML + Razor Syntax
```

Example:

```cshtml
<h1>@ViewData["Title"]</h1>
<p>Welcome to Expert Search.</p>
```

In this example:

```text
<h1> and <p>          -> HTML
@ViewData["Title"]   -> Razor
```

So before learning Razor properly, we must understand HTML.

HTML helps us create:

- MVC pages
- Forms
- Tables
- Buttons
- Navigation
- Login pages
- Dashboard pages
- Admin panel screens
- Details pages
- Create/Edit/Delete pages

## 3. Real-Life Example

Think of a website like a building.

```text
HTML       -> Building structure
CSS        -> Paint and design
JavaScript -> Electrical actions and movement
C#         -> Backend logic
Database   -> Storage room
```

HTML decides what exists on the page.

CSS decides how it looks.

JavaScript decides how it behaves in the browser.

ASP.NET Core MVC decides what data should be sent to the page.

## 4. HTML in MVC Request Flow

When a browser requests an MVC page:

```text
Browser Request
      ↓
Controller Action
      ↓
Model/Data Prepared
      ↓
View File (.cshtml)
      ↓
HTML + Razor Converted into Final HTML
      ↓
Browser Displays Page
```

Example:

```text
/Home/Index
      ↓
HomeController -> Index()
      ↓
Views/Home/Index.cshtml
      ↓
Final HTML sent to browser
```

The browser does not understand C# Razor directly.

The browser only receives final HTML, CSS, and JavaScript.

## 5. Basic HTML Page Structure

A normal HTML page looks like this:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Expert Search</title>
</head>
<body>
    <h1>Welcome</h1>
    <p>This is my first HTML page.</p>
</body>
</html>
```

Explanation:

```text
<!DOCTYPE html> -> Tells browser this is an HTML5 document
<html>          -> Root element of page
<head>          -> Metadata, title, CSS links
<title>         -> Browser tab title
<body>          -> Visible page content
```

In ASP.NET Core MVC, this full structure is usually placed inside:

```text
Views/Shared/_Layout.cshtml
```

Individual views usually contain only body content.

Example MVC view:

```cshtml
<h1>Expert List</h1>
<p>All experts will appear here.</p>
```

Because `_Layout.cshtml` already contains:

```html
<!DOCTYPE html>
<html>
<head>
</head>
<body>
    @RenderBody()
</body>
</html>
```

## 11. Links

Links are created using the `<a>` tag.

Example:

```html
<a href="/Home/Index">Home</a>
<a href="/Experts/Index">Experts</a>
<a href="/Home/Contact">Contact</a>
```

Open link in new tab:

```html
<a href="https://techlambda.com" target="_blank">Techlambda</a>
```

For ASP.NET Core MVC, we commonly use Tag Helpers instead of hardcoded URLs.

HTML style:

```html
<a href="/Experts/Index">Experts</a>
```

MVC Tag Helper style:

```cshtml
<a asp-controller="Experts" asp-action="Index">Experts</a>
```

Recommended for MVC:

```cshtml
<a asp-controller="Experts" asp-action="Index">Experts</a>
```

Reason:

- Cleaner MVC routing
- Less hardcoding
- Easier refactoring
- Better enterprise practice

## 14. Div and Span

### 14.1 Div

`<div>` is a block-level container.

It is used to group larger sections.

```html
<div>

    <p>Name: Rahul Sharma</p>
    <p>Skill: Azure</p>
</div>
```

`<span>` is an inline container.

It is used to style or group small text.

```html
<p>Status: <span>Approved</span></p>
```

Simple difference:

```text
<div>  -> Big block container
<span> -> Small inline container
```

## 18. GET and POST in HTML Forms

### 18.1 GET Form

GET sends data in URL query string.

Example:

```html
<form method="get" action="/Experts/Search">
    <input type="text" name="keyword" placeholder="Search expert">
    <button type="submit">Search</button>
</form>
```

Output URL example:

```text
/Experts/Search?keyword=Azure
```

Use GET for:

- Search
- Filter
- Sorting
- Pagination
- Read-only queries

### 18.2 POST Form

POST sends data inside request body.

Example:

```html
<form method="post" action="/Experts/Create">
    <input type="text" name="name" placeholder="Expert Name">
    <button type="submit">Save</button>
</form>
```

Use POST for:

- Create
- Update
- Delete
- Login
- Registration
- Sensitive operations

```cshtml
<ul>
```

```html
    <li>Azure</li>
    <li>SQL Server</li>
</ul>
```

## 34. Common Mistakes and Fixes

### Mistake 1: Missing Closing Tag

Wrong:

```html
<p>This is paragraph
```

Correct:

```html
<p>This is paragraph</p>
```

Impact:

The browser may display the page incorrectly.

---

### Mistake 2: Using `class` and `id` Incorrectly

Wrong:

```html
<p id="status">Approved</p>
<p id="status">Pending</p>
```

Correct:

```html
<p class="status">Approved</p>
<p class="status">Pending</p>
```

Rule:

```text
id    -> Unique on page
class -> Can be reused
```

---

### Mistake 3: Image Without Alt Text

Wrong:

```html
<img src="/images/logo.png">
```

Correct:

```html
<img src="/images/logo.png" alt="Expert Search Logo">
```

Reason:

`alt` improves accessibility and gives fallback text.

---

### Mistake 4: Form Input Without Name

Wrong:

```html
<input type="text" id="name">
```

Correct:

```html
<input type="text" id="name" name="name">
```

Reason:

The `name` attribute is required to send form value to server.

---

### Mistake 5: Hardcoded MVC URLs Everywhere

Not preferred:

```html
<a href="/Experts/Index">Experts</a>
```

Preferred in MVC:

```cshtml
<a asp-controller="Experts" asp-action="Index">Experts</a>
```

Reason:

Tag Helpers are safer and easier to maintain.

---

### Mistake 6: Putting Full HTML Document in Every View

Wrong in normal MVC view:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Page</title>
</head>
<body>
    <h1>Hello</h1>
</body>
</html>
```

Correct:

```cshtml
@{
    ViewData["Title"] = "Page";
}

<h1>Hello</h1>
```

Reason:

`_Layout.cshtml` already provides the full HTML document structure.

Bad:

```html
<div><h1>Title</h1><p>Text</p><table><tr><td>Data</td></tr></table></div>
```

Good:

```html
<div>
    <h1>Title</h1>
    <p>Text</p>

    <table>
        <tr>
            <td>Data</td>
        </tr>
    </table>
</div>
```

Clean formatting helps team members understand code quickly.

---

### 35.3 Use Forms Carefully

For forms:

- Use proper labels
- Use correct input types
- Use `required` only where needed
- Use POST for data changes
- Use GET for search/filter
- Do not expose sensitive data in GET URL

---

### 35.4 Use MVC Tag Helpers

Prefer:

```cshtml
<a asp-controller="Home" asp-action="Index">Home</a>
```

Instead of:

```html
<a href="/Home/Index">Home</a>
```

---

### 35.5 Separate Structure and Design

HTML should focus on structure.

CSS should focus on design.

Avoid too much inline styling.

Not preferred:

```html
<p style="color:red;font-size:20px;">Error message</p>
```

Better:

```html
<p class="error-message">Error message</p>
```

Then style in CSS:

```css
.error-message {
    color: red;
    font-size: 20px;
}
```

# Subjective Questions

## Q1. What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of a web page using tags such as headings, paragraphs, links, images, tables, and forms.

---

## Q2. Why is HTML important in ASP.NET Core MVC?

HTML is important because MVC views are created using `.cshtml` files, and these views use HTML to define the visible structure of pages. Razor adds dynamic server-side data into the HTML.

---

## Q3. What is the difference between HTML and Razor?

HTML defines page structure. Razor allows C# code to be mixed with HTML in `.cshtml` files. Razor executes on the server and generates final HTML for the browser.

---

## Q4. What is the purpose of the `<form>` tag?

The `<form>` tag is used to collect user input and submit it to the server using methods such as GET or POST.

---

## Q5. What is the difference between GET and POST forms?

GET sends data in the URL and is commonly used for search and filtering. POST sends data in the request body and is commonly used for create, update, delete, login, and registration operations.

---

## Q6. Why should every input have a `name` attribute?

The `name` attribute is used as the key when form data is sent to the server. Without `name`, the server may not receive the input value correctly.

---

## Q7. What is semantic HTML?

Semantic HTML means using meaningful tags such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` instead of using only generic `<div>` tags. It improves readability, accessibility, and maintainability.

---

## Q8. Why is the `alt` attribute important for images?

The `alt` attribute provides alternative text for an image. It helps accessibility tools, improves fallback behavior when an image fails to load, and supports better page understanding.

---

## Q9. What is the difference between `id` and `class`?

`id` should be unique on a page and is used for one specific element. `class` can be reused on multiple elements and is commonly used for styling groups of elements.

---

## Q10. Why should MVC applications prefer Tag Helpers for links?

MVC applications should prefer Tag Helpers because they integrate with MVC routing, reduce hardcoded URLs, improve maintainability, and make navigation easier to refactor.

---
