# Project Vision

## What The System Will Do

The system will allow society members to raise complaints/issues, and society admin or maintenance staff can track, assign, resolve, and close them.

## Main Users

### 1. Resident

A resident can:

* Register/login
* Raise a complaint
* Upload issue photo
* Track complaint status
* Add comments
* Give feedback after resolution

### 2. Society Admin

Admin can:

* View all complaints
* Assign complaints to staff
* Update priority
* Track pending and resolved issues
* Manage users
* View reports

### 3. Maintenance Staff

Staff can:

* View assigned complaints
* Update work status
* Add resolution notes
* Upload proof of completion
