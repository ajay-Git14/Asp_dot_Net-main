# Topic 1: LINQ

## What

LINQ means **Language Integrated Query**.

It allows us to query collections using readable C# syntax.

## Why

Without LINQ, filtering and sorting records requires long loops.

With LINQ, the code becomes readable and business-focused.

## Complaint List Example

```csharp
List<Complaint> complaints = new List<Complaint>
{
    new Complaint { Id = 101, Title = "Lift not working", Status = "New", PriorityScore = 9 },
    new Complaint { Id = 102, Title = "Water leakage", Status = "Assigned", PriorityScore = 7 },
    new Complaint { Id = 103, Title = "Parking issue", Status = "Resolved", PriorityScore = 4 }
};
```

## Filter Using `Where`

```csharp
var pendingComplaints = complaints
    .Where(c => c.Status != "Resolved")
    .ToList();
```

## Select Specific Data

```csharp
var complaintTitles = complaints
    .Select(c => c.Title)
    .ToList();
```

## Sort Data

```csharp
var highPriorityFirst = complaints
    .OrderByDescending(c => c.PriorityScore)
    .ToList();
```

## Get First Matching Record

```csharp
var complaint = complaints
    .FirstOrDefault(c => c.Id == 101);
```

## Check Existence

```csharp
bool hasCriticalComplaint = complaints
    .Any(c => c.PriorityScore >= 8);
```

## Count Records

```csharp
int resolvedCount = complaints
    .Count(c => c.Status == "Resolved");
```

## Project Mapping

```text
Where = Filter complaints
Select = Pick required fields
OrderBy = Sort complaints
FirstOrDefault = Find one complaint
Any = Check existence
Count = Count records
```

# Topic 2: Lambda Expression

## What

A lambda expression is a short way to write inline logic.

## Example

```csharp
c => c.Status == "New"
```

Meaning:

```text
For each complaint c, check whether status is New
```

## Project Example

```csharp
complaints.Where(c => c.PriorityScore >= 8)
```

Meaning:

```text
From all complaints, select only critical complaints
```

## Deep Understanding

A lambda expression is often used to express small business rules inside LINQ.

```csharp
c => c.Status != "Resolved"
```

Business meaning:

```text
Complaint is still pending if status is not resolved.
```

# Topic 3: Nullable Values

## What

Nullable values allow variables to hold no value.

## Why

In real applications, not every field has a value all the time.

Examples:

```text
Complaint may not be resolved yet.
Complaint may not be assigned yet.
Attachment may not be uploaded yet.
Resolved date may be empty.
```

## Example

```csharp
DateTime? resolvedDate = null;
```

## Safe Usage

```csharp
if (resolvedDate.HasValue)
{
    Console.WriteLine(resolvedDate.Value);
}
else
{
    Console.WriteLine("Complaint is not resolved yet");
}
```

## Null-Coalescing Operator

```csharp
string assignedTo = null;

string displayName = assignedTo ?? "Not assigned";
```

## Project Mapping

```text
ResolvedDate = null
    ↓
Complaint is not resolved yet
```

# Topic 4: Exception Handling

## What

Exception handling protects the application from runtime failures.

## Why

Applications may fail because of:

- Invalid input
- Database error
- API failure
- File upload failure
- Null value usage
- Conversion error

## Example

```csharp
try
{
    string input = "abc";
    int complaintId = Convert.ToInt32(input);
}
catch (FormatException)
{
    Console.WriteLine("Invalid complaint ID format");
}
catch (Exception ex)
{
    Console.WriteLine($"Unexpected error: {ex.Message}");
}
finally
{
    Console.WriteLine("Complaint ID processing completed");
}
```

## Project Mapping

Use exception handling when:

```text
Complaint ID conversion may fail
Database save may fail
Attachment upload may fail
Notification sending may fail
External API may fail
```

## Common Mistake

Bad:

```csharp
catch
{
}
```

Better:

```csharp
catch (Exception ex)
{
    Console.WriteLine(ex.Message);
}
```

# Topic 5: Async And Await

## What

`async` and `await` are used for asynchronous programming.

## Why

In ASP.NET Core, long-running operations should not block the application.

Examples:

- Database calls
- API calls
- File uploads
- Email sending
- Report generation

## Simple Example

```csharp
public async Task<string> LoadComplaintMessageAsync()
{
    await Task.Delay(1000);
    return "Complaint data loaded";
}
```

## List Example

```csharp
public async Task<List<Complaint>> GetComplaintsAsync()
{
    await Task.Delay(1000);

    return new List<Complaint>
    {
        new Complaint { Id = 101, Title = "Lift not working", Status = "New", PriorityScore = 9 },
        new Complaint { Id = 102, Title = "Water leakage", Status = "Assigned", PriorityScore = 7 }
    };
}
```

## Deep Understanding

Async does not mean faster CPU execution.

It means the thread is not blocked while waiting for I/O work.

```text
Database/API/File operation is waiting
    ↓
Thread is released
    ↓
Application can serve other requests
    ↓
Result comes back later
```

# Topic 6: Task

## What

`Task` represents an asynchronous operation.

## Example

```csharp
Task<List<Complaint>>
```

Meaning:

```text
This method will return a list of complaints in the future after async work completes.
```

## Common Async Return Types

| Return Type | Meaning |
|---|---|
| `Task` | Async operation with no return value |
| `Task<T>` | Async operation returning value of type T |
| `ValueTask<T>` | Advanced optimized async return type |

# Topic 7: Dependency Injection Readiness

## What

Dependency Injection means a class receives its dependencies from outside instead of creating them directly.

## Why

It makes applications:

- Loosely coupled
- Testable
- Maintainable
- Flexible
- Cleanly structured

## Interface

```csharp
public interface IComplaintService
{
    Task<List<Complaint>> GetComplaintsAsync();
}
```

## Implementation

```csharp
public class ComplaintService : IComplaintService
{
    public async Task<List<Complaint>> GetComplaintsAsync()
    {
        await Task.Delay(500);

        return new List<Complaint>
        {
            new Complaint { Id = 101, Title = "Lift not working", Status = "New", PriorityScore = 9 }
        };
    }
}
```

## ASP.NET Core Registration Style

```csharp
builder.Services.AddScoped<IComplaintService, ComplaintService>();
```

## Future Controller Usage

```csharp
public class ComplaintController : Controller
{
    private readonly IComplaintService _complaintService;

    public ComplaintController(IComplaintService complaintService)
    {
        _complaintService = complaintService;
    }
}
```

## Deep Understanding

Bad design:

```text
Controller creates service directly
```

Better design:

```text
Controller depends on interface
ASP.NET Core injects implementation
```

# Hour 3 Practical Code

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Threading.Tasks;

public class Complaint
{
    public int Id { get; set; }
    public string Title { get; set; } = "";
    public string Status { get; set; } = "";
    public int PriorityScore { get; set; }
    public DateTime? ResolvedDate { get; set; }
}

public interface IComplaintService
{
    Task<List<Complaint>> GetComplaintsAsync();
}

public class ComplaintService : IComplaintService
{
    public async Task<List<Complaint>> GetComplaintsAsync()
    {
        await Task.Delay(500);

        return new List<Complaint>
        {
            new Complaint { Id = 101, Title = "Lift not working", Status = "New", PriorityScore = 9 },
            new Complaint { Id = 102, Title = "Water leakage", Status = "Assigned", PriorityScore = 7 },
            new Complaint { Id = 103, Title = "Parking issue", Status = "Resolved", PriorityScore = 4, ResolvedDate = DateTime.Now }
        };
    }
}

public class Program
{
    public static async Task Main()
    {
        IComplaintService complaintService = new ComplaintService();

        try
        {
            List<Complaint> complaints = await complaintService.GetComplaintsAsync();

            var criticalComplaints = complaints
                .Where(c => c.PriorityScore >= 8)
                .OrderByDescending(c => c.PriorityScore)
                .ToList();

            Console.WriteLine("Critical Complaints:");

            foreach (Complaint complaint in criticalComplaints)
            {
                string resolvedStatus = complaint.ResolvedDate.HasValue
                    ? $"Resolved on {complaint.ResolvedDate.Value}"
                    : "Not resolved yet";

                Console.WriteLine($"{complaint.Id} - {complaint.Title} - {resolvedStatus}");
            }

            int pendingCount = complaints.Count(c => c.Status != "Resolved");

            Console.WriteLine($"Pending Complaints: {pendingCount}");
        }
        catch (Exception ex)
        {
            Console.WriteLine($"Error occurred: {ex.Message}");
        }
    }
}
```

# Hour 3 Common Mistakes

## 1. Forgetting `using System.Linq`

LINQ methods require:

```csharp
using System.Linq;
```

## 2. Calling `.Value` On Nullable Without Checking

Bad:

```csharp
Console.WriteLine(resolvedDate.Value);
```

Better:

```csharp
if (resolvedDate.HasValue)
{
    Console.WriteLine(resolvedDate.Value);
}
```

## 3. Blocking Async Code

Avoid:

```csharp
var result = GetComplaintsAsync().Result;
```

Prefer:

```csharp
var result = await GetComplaintsAsync();
```

## 4. Catching Exception But Ignoring It

Bad:

```csharp
catch
{
}
```

Better:

```csharp
catch (Exception ex)
{
    Console.WriteLine(ex.Message);
}
```

## 5. Creating Services Directly Inside Controllers

Avoid:

```csharp
ComplaintService service = new ComplaintService();
```

Prefer dependency injection:

```csharp
private readonly IComplaintService _complaintService;
```

using System;
using System.Collections.Generic;
using System.Linq;
using System.Threading.Tasks;

public class Complaint
{
    public int Id { get; set; }
    public string Title { get; set; } = "";
    public string Category { get; set; } = "";
    public string Status { get; set; } = "New";
    public int PriorityScore { get; set; }
    public DateTime? ResolvedDate { get; set; }
}

public interface IComplaintService
{
    Task<List<Complaint>> GetComplaintsAsync();
}

public class ComplaintService : IComplaintService
{
    public async Task<List<Complaint>> GetComplaintsAsync()
    {
        await Task.Delay(500);

        return new List<Complaint>
        {
            new Complaint
            {
                Id = 101,
                Title = "Lift not working",
                Category = "Maintenance",
                Status = "New",
                PriorityScore = 9
            },
            new Complaint
            {
                Id = 102,
                Title = "Water leakage",
                Category = "Maintenance",
                Status = "Assigned",

                Title = "Parking issue",
                Category = "Security",
                Status = "Resolved",
                PriorityScore = 4,
                ResolvedDate = DateTime.Now

public class Program
{
    public static async Task Main()
    {
        IComplaintService complaintService = new ComplaintService();

        try
        {
            List<Complaint> complaints = await complaintService.GetComplaintsAsync();

            Console.WriteLine("Smart Society Complaint Summary");

            int totalComplaints = complaints.Count;

            Console.WriteLine($"Total Complaints: {totalComplaints}");
            Console.WriteLine($"Pending Complaints: {pendingComplaints}");
            Console.WriteLine($"Resolved Complaints: {resolvedComplaints}");
            Console.WriteLine();

            Console.WriteLine("Critical Complaints:");

            var criticalComplaints = complaints
                .Where(c => c.PriorityScore >= 8)
                .OrderByDescending(c => c.PriorityScore)
                .ToList();

            foreach (Complaint complaint in criticalComplaints)
            {
                string resolvedInfo = complaint.ResolvedDate.HasValue
                    ? $"Resolved on {complaint.ResolvedDate.Value}"
                    : "Not resolved yet";

                Console.WriteLine($"{complaint.Id} - {complaint.Title} - {complaint.Status} - {resolvedInfo}");
            }
        }
        catch (Exception ex)
